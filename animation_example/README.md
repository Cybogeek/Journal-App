# Animation Demo App

A Flutter app demonstrating three different animation techniques across three screens with navigation.

## Screens

1. **AnimatedContainer Screen**  
   Shows changes in size, color, and border radius using `AnimatedContainer`.

2. **AnimatedOpacity Screen**  
   Fades a box in and out using `AnimatedOpacity`.

3. **AnimationController Screen**  
   Rotates and scales an icon using `AnimationController`, `Tween`, and `AnimatedBuilder`.

## Navigation

The bottom navigation bar allows switching between the three screens.

## Animation Techniques Used

- **AnimatedContainer**: For smooth property changes (size, color, borderRadius).
- **AnimatedOpacity**: To fade widgets in and out.
- **AnimationController**: For custom animations with rotation and scale effects.

## Features

- No overflow errors
- Responsive layout with proper padding
- Simple state management
- Built using only Flutter SDK (no external packages)

## How to Run

1. Copy the project repo, then run the app

```
flutter run

```

## Practical Use Cases

- Expandable cards: AnimatedContainer
- Show/hide elements: AnimatedOpacity
- Loading effects, buttons, icons: AnimationController
